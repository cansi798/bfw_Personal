# Videos

Videodatei einfach in diesen Ordner legen und so benennen:

- `tag01.mp4` für Tag 1, `tag02.mp4` für Tag 2 und so weiter bis `tag10.mp4`
- ein zweites Video am selben Tag `tag03_2.mp4`, ein drittes `tag03_3.mp4`
- erlaubt sind auch `.webm`, `.mov` und `.m4v`

Die Lernseite findet die Datei von selbst und zeigt sie beim richtigen Tag an. Nach dem Hochladen dauert es etwa eine Minute.

Größe
- Upload im Browser auf github.com höchstens 25 MB je Datei
- Upload mit GitHub Desktop oder git höchstens 100 MB je Datei
- Größere Videos vorher verkleinern (zum Beispiel mit HandBrake, Voreinstellung „Fast 720p30“) oder als YouTube-Link in `videos.js` eintragen
