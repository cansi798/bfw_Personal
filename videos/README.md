# Videos

Pro Unterrichtstag gibt es zwei Videos, eins zum Vormittag und eins zum Nachmittag (jeweils Unterricht zu Präsentation und Skript). Datei einfach in diesen Ordner legen und so benennen:

| Tag | Vormittag | Nachmittag |
|---|---|---|
| Tag 1 | `tag01_vormittag.mp4` | `tag01_nachmittag.mp4` |
| Tag 2 | `tag02_vormittag.mp4` | `tag02_nachmittag.mp4` |
| ... | ... | ... |
| Tag 9 | `tag09_vormittag.mp4` | `tag09_nachmittag.mp4` |
| Tag 10 (Ganztag) | `tag10_ganztag.mp4` | |

- Ein zweites Video zur selben Session bekommt `_2` am Ende, zum Beispiel `tag03_vormittag_2.mp4`.
- Erlaubt sind `.mp4`, `.webm`, `.mov` und `.m4v`. Am sichersten ist `.mp4`.
- Die Lernseite findet die Datei von selbst und zeigt sie bei Vormittag bzw. Nachmittag des Tages an. Nach dem Hochladen dauert es etwa eine Minute.

Größe
- Upload im Browser auf github.com höchstens 25 MB je Datei
- Upload mit GitHub Desktop oder git höchstens 100 MB je Datei
- Größere Videos vorher verkleinern (zum Beispiel mit HandBrake, Voreinstellung „Fast 720p30“) oder als YouTube-Link in `videos.js` eintragen
